# RPGS
Scripts used in the "Progeny-based genomic selection reveals untapped genetic potential in an underutilized medicinal plant, *Perilla frutescens*"

This repository contains materials related to the preprint:

Kinoshita, S., Sakurai, K., Tsusaka, T., Sakurai, M., Shirasawa, K., Isobe, S., & Iwata, H. (2025). 
*Progeny-based genomic selection reveals untapped genetic potential in an underutilized medicinal plant, Perilla frutescens*. 
bioRxiv. https://doi.org/10.1101/2025.11.26.690889

Please cite the preprint above if you use this repository.
